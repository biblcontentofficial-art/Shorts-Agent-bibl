# BRIEF.md 템플릿 (projects/<p>/BRIEF.md)

인터뷰로 정한 답을 적는다. 다음 세션·다른 에이전트는 이 파일에서 이어가고 다시 묻지 않는다. 답을 바꾸려면 이 파일을 고친다.

```markdown
# <프로젝트> BRIEF
- 원본: <절대경로> (<길이>, <해상도> <fps>)
- 브랜드: mathclient | bibl | bibl-classic
- 편수: 기준 통과 전부 | N편
- 길이: 브랜드 기본(mathclient 40~100, 이상 60~90 / bibl 30~75) | 지정
- 모션 레벨: 0 | 1 | 2  (느낌: smooth | snappy | bouncy …)
- 자막 스타일: brand | pop | karaoke | highlight | fade
- 컷확인 단계: 한다 | 건너뛴다
- 금지: (예) BGM 없음 · 효과음 없음 · 사진 금지
- 납품: 작업 폴더만 | 브랜드 납품 폴더(승인 후) · SNS 압축본 여부
- 결정 기록:
  - YYYY-MM-DD 사용자: "…" → 반영 내용
```
