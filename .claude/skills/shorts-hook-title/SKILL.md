# 쇼츠 후킹 제목

화면 상단에 쇼츠 내내 떠 있는 2줄 제목. **사용자가 고른 뒤에만 최종 렌더**하고, 사용자가 쓴 문구는 띄어쓰기까지 그대로 올린다(업로드 제목은 맞춤법을 다듬은 판을 따로 둘 수 있음).

## 공통 원칙
- **화자가 말하지 않은 수치·성과·교재명으로 단정하지 않는다.** 가린 내용(이것만·이걸)은 본문에 반드시 나와야 한다(낚시 금지).
- 대시(—) 금지 · 해법 없는 열린 의문형 종결 금지 · 회차 넘버링·개인 일화 앞세우기 금지(저성과).
- 4안은 **각도가 달라야** 한다(같은 문장의 어미 변주 금지): A 기본형 / B 단정·선언형 / C 숫자·인용 압축형 / D 반전·저격형(보조).
- 폭은 엔진이 자동 축소하지만, 한 줄이 너무 길면 글자가 작아진다 — 줄당 권장 글자수를 지킨다.
- 제출 형식 (`shorts/<id>/titles.md`):
```markdown
| 안 | 1줄 | 2줄 | 각도 | 근거(본문 시각) |
|---|---|---|---|---|
| A ★ | 내신 수학 1등급은 | 이것만 알면 됩니다 | 은폐 | 03:12 "…" |
응답: "1. A / 2. 직접: ○○/○○ / 3. 삭제"
```

## 수학쌤 (brand mathclient)
- **카피는 항상 존댓말**(자막은 화자 말투 그대로 — 반말 편이어도 제목은 존댓말).
- 1줄 8~16자, 2줄 6~12자.
- **A안 기본 = 은폐형**: ① 1줄 보편 앵커(시점·상황·욕망: "내신 수학 1등급은", "530등에서 수학1등") ② 2줄에 **"이것만"**(은폐 + 하나만 하면 된다는 단일성) ③ 쉬운 구어 단정("~면 됩니다 / ~했습니다 / ~서 그래요"). 확정 예: "내신 수학 1등급은 / 이것만 알면 됩니다", "530등에서 수학1등 / 이것만 했습니다", "수학 점수 안오르는 사람은 / 이걸 건너 뛰어서 그래요"(사용자 원문 그대로).
- 좁은 타겟 호명·저격형은 D안으로 미룬다.
- 금기(brief): 교재명·출처 오표기, 학생을 깎아내리는 프레임, 성적 보장 카피, 경쟁 강사 비방.

## 비블 (brand bibl)
- 공식(2026-08 확정, 비블 첨삭 학습): **결과 우선**("조회수를 폭발시키는") · **실행 명사로 끝**(방법·공식·기준·설정) · **최대 실적 숫자**(구체 숫자) · **호기심 갭**("이 방식") · **단호한 확언체**("~하면 됩니다/망합니다/입니다"). '~하는 이유' 설명형 금지.
- 제목 한 줄로 받아도 엔진이 균형 2줄로 나눈다(split2). 현행 템플릿(bibl, v2)은 **1줄 노랑(#FFCC22)·2줄 흰색** → 1줄에 결과·숫자 같은 걸림돌을, 2줄에 대상·행동을 둔다. 구 템플릿(bibl-classic)은 1줄 흰·2줄 노랑.
- 승인 전에는 파일명 확정 금지 — 비블은 납품 파일명 = 승인된 제목.
- **사용자가 직접 고친 확정 예(2026-09-28, bibl_ex1 7편 — 후보를 이 방향으로)**: '모두가 베끼는 시대'(1줄) · '어차피 99%는 안하니까 / 다 알려주는게 전략입니다' · '3일 만에 1,400억 판 / 사업가의 한 문장' · '똑같이 해도 결국 / 큰 돈을 버는 사람의 특징' · '노하우를 아끼는 순간 / 매력이 다 사라지는 거에요' · '기획이 막막하다면 / 딱 1가지만 하세요' · '사업이 쉬워지는 / 가장 효과좋은 방법'. 읽히는 취향: 화자 인용을 그대로 옮기기보다 **시청자 이득·통념 뒤집기로 넓게**(시대·전략·특징·방법·1가지), **구어체 끝맺음**('~거에요', '~하세요'), '어차피·결국·딱·가장' 같은 힘주는 부사, 사례 숫자는 권위용으로만(3일 만에 1,400억). 후보를 낼 때 이 결의 안을 최소 하나 넣는다. 사용자가 쓴 문구는 띄어쓰기·맞춤법까지 그대로(표준 표기는 한 줄로만 알림).
- 현행 템플릿 v3(bibl-v3): 가운데 #2C2929 상자·흰 글자 66px·폭 712px(2줄 각 약 11자). 짧은 구호는 `title.one_line: true` 로 한 줄 그대로(아니면 엔진이 균형 2줄로 나눔).

## 업로드 제목·설명 (요청 시)
- 업로드 제목 = 화면 2줄을 한 문장으로 이은 것(40자 이내 권장), 맞춤법은 다듬는다.
- 설명·캡션은 **그 쇼츠의 자막(out/<id>.srt)만 근거**로 쓴다. 없는 숫자·주장 금지, 쓴 뒤 SRT 와 한 번 더 대조. 해시태그는 브랜드 고정 3개 + 주제 2개.
