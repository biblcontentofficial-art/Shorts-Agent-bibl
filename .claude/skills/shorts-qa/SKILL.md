# 쇼츠 검수

`./shorts.sh qa <p>/<id>` → `out/<id>_qa.json`. 기계 판정(PASS/WARN/FAIL) 위에 사람 눈 검수와 규칙 대조를 더해 `out/<id>_review.md` 를 쓴다. **게이트 통과는 필요조건일 뿐 좋은 영상의 증거가 아니다**(HyperFrames 가이드 'Iterating').

## 1. 자동 검수 9종 — 읽는 법
| 검사 | FAIL/WARN 이면 | 흔한 원인 → 고칠 곳 |
|---|---|---|
| format | 해상도·fps·길이(±1프레임)·yuv420p·48kHz | render 재실행. 반복되면 엔진 보고 |
| timestamps | 첫 PTS ≥ 1프레임·오디오 시작 어긋남 | 업로드 후 앞부분 빨리감기 사고의 원인 — render 재실행 |
| loudness | 목표 ±1 LU 밖·트루피크 > -1 | 효과음 vol 과다 → sfx vol 낮춤 |
| audio_head | 첫 1.3초 평균 < -45dB | 앞에 무음 — segments[0].in 을 첫 단어로 |
| cut_edges | 소리가 실제로 끊기는 편집점(맨 앞·끝·skip·구간 사이)의 음량이 말소리 중앙값 −10dB 보다 큼 | 음절 잘림 의심 — 그 경계 in/out 을 0.1초 단위로 조정 또는 skip 구절 확인. 샷 경계로만 나뉜 연속 구간은 검사하지 않는다(소리가 이어짐). skip 경계가 '확인 권장'으로 보정된 곳이면 쉼 없는 말 사이라 WARN 이 정상 — 사람이 들어 확인 |
| transcript | 재전사 일치율 < 0.85, 첫·끝소리 다름(첫: 앞 3글자 중 같은 자리 2글자 — 표기 한 글자 차이는 통과, 첫 음절이 빠져 밀리면 경고 · 끝: 끝 2글자 일치, Whisper 의 반말→존댓말 표기(거야/거예요)는 같은 꼴로 보고 비교), **어절 차이 목록** | 끝 음절 잘림(out +0.1~0.2) · 다음 문장 첫소리 유입(out −) · skip 한 말이 남음 · 전사 오인식 후보(예: 자막 '시험 문제를' ↔ 들림 '쉬운 문제를') — 띄어쓰기 차이는 무시, 뜻이 다른 차이는 사용자 확인 |
| faces | 얼굴 미검출·가장자리·글자에 가림 | 가장자리: 가상 카메라 데드존/focus · 가림: beat zone "alt" 또는 크기 ↓ |
| layout | 화면 밖·자막 폭 초과·그래픽-자막 겹침 | 문구 줄이기·size ↓·zone 변경 |
| hf_check | 런타임 오류·넘침·겹침 | compose 결과 문제 — 엔진 보고 |

## 2. 눈 검수 (시트 `out/<id>_sheet.jpg` 필수)
- **시작 0.3초**: 이전 장면 꼬리·흰 카드·암전 없음, 얼굴 정상.
- **컷 이음새 앞뒤**: 다른 샷이 한 프레임이라도 비치지 않음, 점프컷 위치가 어색하지 않음.
- **25/50/75%·끝**: 제목 잘림·자막 줄바꿈 어색(조사 하나만 남은 줄 등)·그래픽이 얼굴/자막을 가림·강조색 두 개 이상.
- 의심되면 그 시각 프레임을 직접: `ffmpeg -ss <t> -i out/<name>.mp4 -frames:v 1 /tmp/x.png`.

## 3. 규칙 대조
- 제목: 승인 문구와 한 글자까지 같은가(`title.status: approved`), 존댓말·대시·열린 의문형(수학쌤).
- 자막: 화자 말투 그대로, 교정 사전 반영(교재명), 문장부호 규칙(비블 전면 제거·수학쌤 끝 마침표만 제거), 한 줄 폭.
- 그래픽: at_word 시각에 뜨는가(말보다 먼저 뜨면 스포일러), 모션 레벨을 넘지 않는가, '큰 순간' 하나, 화자가 안 한 말·수치 없음.
- 브랜드 템플릿 위치·크기(수학쌤 기준: 제목 글자 y 99~329·자막 윗선 1097·시그니처 1756, 제목 1줄 기준).

## 4. review.md 형식
```markdown
# <id> 검수 — 판정 PASS | WARN | FAIL
| # | 시각 | 무엇 | 고칠 값(절대값) | 근거 |
|---|---|---|---|---|
| 1 | 12.4s | 키워드 카드가 자막과 겹침 | beats[1].zone = "alt" | 시트 50% |
자동 검수: format ✓ … (qa.json 요약)
사용자 확인 필요: (판단이 애매한 것)
```
수정 지시는 editor 가 그대로 옮길 수 있게 **필드와 값**으로 쓴다. "조금" 같은 상대 표현 금지.

## 5. 루프
editor 반영 → build → render → qa 재실행. 최대 2회. 남은 문제는 사용자에게 사실대로(무엇이 남았고 왜 못 고쳤는지).
