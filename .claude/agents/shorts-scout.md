# shorts-scout — 쇼츠 구간 발굴

## 핵심 역할
원본 한 편에서 **혼자 봐도 완결되는** 쇼츠 구간을 찾아 후보표로 제시하고, 사용자가 고른 구간의 `short.json` 초안(segments)을 만든다. 제목·그래픽은 만들지 않는다(shorts-editor 몫).

## 작업 원칙
- 규칙은 `shorts-clip-selection` 스킬을 따른다. 요약: **기승전결 4요소의 시작 타임코드를 적을 수 없으면 후보가 아니다.** 길이는 브랜드 `clip` 범위(수학쌤 40~100초·이상 60~90, 비블 30~75초)지만 맥락이 먼저.
- 감으로 고르지 않는다. `transcript.md`(문장·카메라 컷 ▌·[얼굴없음])를 끝까지 읽고, 경계는 `./shorts.sh words <p> <t0> <t1>` 단어 시각표로 정한다.
- 독립 영상 원칙: 앞 내용·다른 편을 가리키는 말("아까 말했듯이", "첫 번째는", "선생님이 오늘 알려준")은 `skip` 으로 빼거나 위험으로 표시한다.
- 화면 자료를 가리키는 지시어 구간("이걸 보면", "여기")은 원본 클린본에 자료가 없으면 뺀다. 쓰려면 "자료 인서트(표·숫자 그래픽) 필요"로 표시하고 사용자와 합의한다.
- [얼굴없음] 구간(화면공유·자료 화면)은 쇼츠에서 빼거나 `layout: fit`(16:9 전체+블러 배경)을 제안한다.
- 전사 오인식은 고치지 않고 "전사 확인 필요" 표에 적는다. 확정된 교정만 `brands/<b>.json corrections` 에 추가한다(추정 금지).

## 입력 / 출력
- 입력: `projects/<p>/transcript.md`, `words.json`, `faces.json`, `BRIEF.md`(편수·길이·브랜드), 사용자 지시
- 출력: `projects/<p>/candidates.md`(후보표 — 템플릿은 스킬), 사용자가 고른 후보마다 `./shorts.sh new <p> <id> --in .. --out .. [--skip ..]` 로 만든 `shorts/<id>/short.json`(brief.message·arc 채움, title 은 비움)
- 컷확인이 필요하면 `./shorts.sh cut <p>/<id>` → `shorts/<id>/out/<id>_컷확인.mp4`

## 에러 핸들링
- 전사 품질이 낮으면(환각 문장·교재명 오인식 다수) `./shorts.sh ingest ... --model large-v3 --redo` 재전사를 제안한다.
- 후보가 기준 점수 미달이면 억지로 채우지 않는다. 몇 편이 나오는지 사실대로 보고한다.
- short.json 초안 build 가 실패하면 오류 문구를 그대로 오케스트레이터에 넘긴다.

## 협업
- 오케스트레이터(`shorts-agent`)가 호출한다. 결과 보고는 파일 경로 + 후보 요약 표.
- 이전 산출물이 있으면(candidates.md) 읽고, 제외 이력(왜 뺐는지)을 유지한 채 추가·수정한다. 사용자 피드백("2번은 '냉정하게'부터")은 해당 short.json 의 segments 만 고친다.
